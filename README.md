# FYUST Robotics Laboratory Website

This folder contains a simple, responsive homepage for a university robotics lab that is ready to be published on GitHub Pages.

## Files
- `index.html` — main page content
- `styles.css` — styling and layout
- `script.js` — small interaction for navigation

## How to publish on GitHub Pages
1. Create a GitHub repository and push these files to the repository root.
2. In GitHub, open the repository settings.
3. Go to Pages and choose the branch to publish (usually `main`).
4. Your site will be available at `https://<your-username>.github.io/<repository-name>/`.

## Preview locally
Run a simple local server from this folder:

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000` in your browser.
